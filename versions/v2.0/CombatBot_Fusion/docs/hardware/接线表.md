# 接线表（ESP32-S3 DevKitC-1 N16R8）

> 所有跨 3.3V / 5V 的信号**必须**经过双向逻辑电平转换器；FG 必须分压到 3.3V。
> 24V 电机电源与 ESP32 **电源分离、地共接**（星型单点接地），否则电机启停会复位主控。

## 1. 电源树

```
24V 锂电（满电 ~25.2V / 亏电 ~21V）
 ├─ 直接供 4× JGB37-3625（峰值 4~8A）  ── 电机侧并 470µF 电解 + 0.1µF 陶瓷
 └─ DC-DC 24V→5V (≥5A) ── 舵机 + 传感器 5V + ESP32 5V/VIN
        └─ ESP32 板载 LDO → 3.3V（5V 入口并 220µF）
```

## 2. 主控引脚分配

| 功能 | GPIO | 去向 / 说明 |
|---|---|---|
| CD74HC4067 SIG | **4** | ADC1_CH3（**必须用 ADC1**：开 WiFi 时 ADC2 不可用） |
| CD74HC4067 S0 / S1 / S2 / S3 | **5 / 6 / 7 / 8** | 通道地址 |
| I²C SDA / SCL | **9 / 10** | MPU6050(0x68) + ADXL345(0x53) + MCP23017(0x20) 共用 |
| 舵机 PWM | **11** | 50Hz，经电平转换到 5V |
| M1 左前 DIR / PWM / FG | **12 / 13 / 14** | |
| M2 右前 DIR / PWM / FG | **15 / 16 / 17** | |
| M3 左后 DIR / PWM / FG | **18 / 21 / 38** | |
| M4 右后 DIR / PWM / FG | **39 / 40 / 41** | |
| 备用 | 1 / 2 / 42 / 43 / 44 / 47 / 48 | GPIO1/2 也是 ADC1，可作模拟备份 |

已避开：GPIO0/3/45/46（strapping）、19/20（USB D-/D+）、26~37（Flash/PSRAM）。

## 3. 电机（4× JGB37-3625，自带驱动板，四线制）

| 线色 | 含义 | 处理方式 |
|---|---|---|
| 红 / 黑 | 24V 电源 ± | 直接接电池，不进 MCU |
| 白 | 方向：悬空/高=CCW，低(≤0.6V)=CW | GPIO 推挽 → 电平转换 → 5V |
| 蓝 | 调速：0~5V 模拟电压 | LEDC 20kHz/10bit → 电平转换到 5V → RC 低通(1kΩ+0.1µF, fc≈1.6kHz) |
| 黄 | FG 测速脉冲（5V 方波） | **1kΩ+2kΩ 分压到 3.33V**（或经电平转换）→ GPIO 中断计数 |

**禁止使用 TB6612 / L298N / 任何 H 桥** —— 该电机自带驱动板，方向+调速即可。

## 4. 传感器

| 器件 | 接口 | 通道 / 引脚 |
|---|---|---|
| 红外测距 GP2Y0A02YK0F ×6 | CD74HC4067 CH0~CH5 | CH0=前 CH1=后 CH2=左前 CH3=右前 CH4=左后 CH5=右后 |
| 电池电压检测 | CD74HC4067 CH6 | 100kΩ + 10kΩ 分压（24V→2.18V） |
| 灰度 NCHD1 ×4（数字量） | MCP23017 GPA0~GPA3 | 灰度 1~4 |
| 光电开关 E18-D80NK ×3 | MCP23017 GPA4~GPA6 | E18 1~3 |
| MPU6050 | I²C 0x68 | Z 轴角速度 → 偏航角 |
| GY-291 / ADXL345 | I²C 0x53 | 倾角 / 翻车 / 冲击（**无陀螺仪，不用于偏航**） |
| 15kg 双轴舵机 | GPIO11 | 500~2500µs |

## 5. 上电前必查

- [ ] FG 是否已分压到 3.3V（**5V 直连会烧毁 IO**）
- [ ] 蓝线调速是否为 5V（3.3V PWM 只能跑到 2/3 速度）
- [ ] 24V 与 5V 是否共地、电机电源是否加 470µF 去耦
- [ ] ESP32 天线区是否留 10mm 净空（不贴金属顶板）
- [ ] I²C 三器件地址无冲突（0x68 / 0x53 / 0x20）
