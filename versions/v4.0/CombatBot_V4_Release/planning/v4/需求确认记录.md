# V4 需求确认记录

> 设计阶段归档：以下保留当时的调研、候选方案和待确认事项，不是最终部署指南；最终采用单车专属控制链接、无账户/选车、独立域名 combatbot.luo-jin-ai.com，自主任务断云继续，控制权需手动接管。当前功能与证据见 [V4发布说明](../../docs/releases/V4.0.md)，公网配置与回退见 [服务器部署](../../docs/setup/V4服务器部署.md)。

## 已确认

- 以当前 V3 为基础，继续提供分文件 Arduino 工程、维护源码与工程风格中文注释。
- AP 本地模式保持原有使用方式；STA 联网后支持服务器托管网页与跨网络遥测、控制。
- 比赛支持车端全自动格斗、人工干预，以及地图点击导航。
- 仅用现有传感器，位置属于估计；显示置信度，支持人工设置初始位姿。
- 活动范围包括低层外圈启动区和中央高台，需要自主登台。
- 用户记忆中的登台方式为无坡道、直接冲上台。设计需包含有界尝试和失败退出；现有机械能力与登台成功判据未经实车验证。
- 尚未装车。用户授权开发方决定安装方式，后续按图安装，不再要求用户提供已有安装信息。
- 安装方向：四路灰度朝下位于四角；三路 E18 朝下位于前左、前右及后方；红外测距按周向向外探测。
- E18 的地面存在状态与危险状态应按角色分开解释；不得沿用所有数字输入 true 均为危险的旧约定。
- 软件验证完成后交付，不烧录、不声称已经通过上板或比赛验证。
- V1/V2/V3 源码、说明与展开式更新记录完整保留，新记录向顶部追加，旧标签不移动。
