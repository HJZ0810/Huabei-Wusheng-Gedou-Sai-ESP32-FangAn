# V4 自主控制与估计定位

V4 在 V3 的统一控制任务内加入自主模块，不增加另一套电机输出任务。使用现有 FG、惯性、灰度与红外；网页呈现估计位置、层面、目标与质量，人工起点负责建立世界参考。

## 场地与层面

几何依据：[waodfi / Combat-Robot-Arena](https://github.com/waodfi/Combat-Robot-Arena)，本次读取提交 `911ddac832ec8dcdc6c7db2acc4f174b74a3fe6e`。默认围栏内场 380 × 380 cm、中央高台 240 × 240 cm、外圈约 70 cm、围栏约 20 cm，台边标注约 6 cm；具体实物以测量为准。本仓库安装图为原创，不复制该项目图片。

世界中心为 `(0,0)`，X 向右、Y 向上，航向从 +X 逆时针为正。导航将车身半对角线、安全余量和位置误差加入边界膨胀；外圈规划绕过中央障碍，高台导航在内缩区域内进行。

| 层面 | 含义 | 自动行为 |
|---|---|---|
| `unknown` | 尚未建立参考 | 等人工锚定 |
| `lower` | 人工设置的外围低层 | 绕台导航，或走入口登台 |
| `upper_anchored` | 人工设置的高台参考 | 高台安全区域导航/格斗 |
| `upper_estimated` | 登台事件链推断的高台 | 保留额外误差，继续已授权任务 |
| `transition_unknown` | 登台中或不足以确定层面 | 限制恢复；失败后停下待校正 |

进入地图中央区域不代表已经登台；位置坐标不会被强行夹回场地内。点选台边危险带、超出安全区域的点或当前不支持的自动下台目标，会被拒绝。

## 定位质量怎样变化

四轮脉冲均值提供本周期行程，融合偏航提供航向增量；用中点航向积分 X/Y。相同时间戳的增量不重复消费，非有限数、异常周期及超大增量被拒绝。

误差规模随累计行程、转角和时间增长，冲击/饱和事件进一步降级，登台成功估计额外增加误差。它是保守启发式模型，**不是实测厘米精度，也不是统计置信区间**。单相 FG 不测真实方向，打滑、被推和机身无轮转动仍会使估计偏离实际。

当前实现没有利用灰度或 IR 自动把估计位置吸附到某条边，也没有承诺由数字传感器恢复绝对坐标。已知地图只用于安全约束、绕台与排除相符外墙回波。误差过大或无法证明车身在活动区域时停止，停车后人工修正起点与层面。

## 导航与任务组合

低层使用固定容量可见图，起点、终点和膨胀台面四角共同组成绕行路线；避免把直线穿过高台当作可通行道路。高台导航根据目标方位转向，再以有限速度接近。

`arenaEntryHeading` 选择从哪一侧朝台内进入：0° 西侧、90° 南侧、180° 东侧、−90° 北侧。该侧的沿边坐标提供入口偏置，入口距台面的法向距离由车身、安全余量与当前误差派生；它不是未经检查即可执行的任意固定落点。

从低层启动自主格斗且允许登台时，自动执行入口导航、对正、登台和寻敌。低层点选安全高台目标时，同样先登台，再继续原目标导航；登台后误差增加会重新检查目标，不能沿用原准入结论。独立登台完成后停稳，不自动转入格斗。

任务组合保留最初总期限，不因成功登台或模式内切换延长期限。安装和校准完成之前 `arenaEnabled`、`arenaCalibrated`、`arenaClimbEnabled` 默认关闭。

## 登台证据链与退出

入口对正且姿态稳定后，在速度、时间和行程预算内尝试直接爬阶。充分事件链包括：入口/方向一致、有效倾角上升、轮行程有进展、倾角回落、估计整个车身进入保守台内区域，以及地面支撑与停车状态持续稳定。停稳按实际增量/周期换算速度判断：不高于0.8cm/s、2°/s持续450ms，不能把控制周期很短时的每拍小增量当作停车。

冲击、加速度饱和、只有计时或只有 FG 行程均不构成完整成功证据。必要地面输入缺失、IO/IMU 失效、倾角过大、无进展到期、距离超限或入口偏离会终止尝试。失败保留未知过渡层，等待人工检查与重新锚定，不无限冲击重试。

满足链条后层面标为 `upper_estimated`，额外扩大误差，继续原任务。这是用户接受的传感器估计策略；撞墙、被顶起或其它起伏仍可能产生相似证据，不能宣传为绝对确认或机械能力认证。

## 格斗与防掉优先级

搜索阶段有限角速扫描；至少三次独立且一致的新采样有效测距形成目标候选，重复读取同一缓存不增加证据或刷新候选时间，然后对准、接近、有限推撞。推撞达到时限或候选过期后结束该次进攻，短时撤离后重新搜索。单路噪声和无效测距不直接触发进攻；与已知外墙距离一致的回波保守排除。

候选不能证明对方身份。防掉不依赖“看见敌人”：E18 见地为 `true`，原始缺地先进入安全路径；前危险向后撤、后危险向前移，前后同时危险停止。脱边动作也有时间/距离限制，恢复需要稳定支撑，返回格斗后重新形成候选而不恢复旧推撞。

灰度亮色只在已知高台且预测探头接近台边时辅助避边；中央红图案与外圈黄蓝区不一概视为边缘。未知层面和必要输入失效优先停止。IR 近场在格斗中与普通避障语义区分，但不会豁免地面支撑、急停、换向等待或堵转。

## 云断网与人工接管

自主行为在车端运行，云端只投递有界任务和控制请求。自主启动后普通云断线不取消任务，本机仍执行采样、避边、错误处理和总期限；连接恢复后可查看状态或明确接管。手动云驾驶采用独立心跳期限，失联停车，不混用自主继续策略。

停止/急停与人工接管经过主控制器门控；自主取消后旧任务不能恢复。设备重启不自动续跑，网页上的旧遥测也不等于仍在执行。部署状态及网络验收以 [V4 发布记录](../releases/V4.0.md) 为准。

## 验证职责

纯 C++ 模块与生产控制共用，主机测试覆盖估计增量、跨层任务、路由、风险优先级、状态预算、登台证据不足和错误输入。它们只能验证软件判断，不能替代上板采样、光照反射、机械爬阶、多核时延或撤输出后的滑行试验。
