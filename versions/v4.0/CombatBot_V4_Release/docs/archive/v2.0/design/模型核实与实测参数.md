# 模型核实与实测参数（ESP32-S3 格斗车）

> 数据来源记录：`轮式格斗小车.STEP`（SolidWorks 2025 导出，34MB）、`轮式格斗小车3.zip`（98 个 SLDPRT/SLDASM 零件）、用户截图 9 张、用户实测轴距/轮距。原始资料未随当前仓库提供。
> 核实方法：① 解压 zip 直接读零件名；② 正则解析 STEP 的 `TOROIDAL_SURFACE` / `CYLINDRICAL_SURFACE` / `CARTESIAN_POINT` 实体，统计几何半径。
> 本文档结论已同步到[详细设计方案](详细设计方案_ESP32S3格斗车.md)。

---

## 1. 三个未知参数，全部确认

| 参数 | 数值 | 确认方式 | 置信度 |
|---|---|---|---|
| **轮径 D** | **72.0 mm**（周长 C = 226.19mm） | STEP 中恰好 4 个圆环面外径 = 72.0mm（R=30.5 + minor 5.5），对应 4 个轮子；与 zip 零件名 `72mm轮子.SLDPRT` 互证 | ★★★ 双重印证 |
| **减速比 i** | **10 : 1**（24V 空载 600rpm） | zip 电机装配体名 `JGB37-3625 Φ6 15MM(6.25-10速比)`；6000rpm 基速 ÷ 600rpm = 10 | ★★★ 双重印证 |
| **轴距 L** | **154 mm** | 用户实测 | ★★★ |
| **轮距 T** | **170 mm** | 用户实测 | ★★★ |

> 至此，运动学公式所需的全部机械参数**已集齐，无需再实测任何尺寸**，剩下的只有固件侧的三步标定（零偏/行程/转向）。

## 2. 由参数推导的关键运动学数值

| 项 | 计算 | 结果 |
|---|---|---|
| 轮周长 C | π × 72 | **226.19 mm** |
| 空载最高车速 | 600rpm ÷ 60 × 226.19mm | **≈ 2.26 m/s**（网页默认限速建议 100cm/s，上限 220） |
| 前进 100cm 所需轮转数 | 1000 ÷ 226.19 | **4.42 圈** |
| 原地转 90° 单侧轮行程 | (π/2) × 170 ÷ 2 | **133.5 mm**（0.59 圈） |
| 原地转 360° 单侧轮行程 | π × 170 | **534.1 mm**（2.36 圈） |
| FG 角度分辨率（估算） | 若 FG=9 脉冲/电机转 × 速比10 → 90 脉冲/轮转；转 90° ≈ 53 脉冲 | **约 1.7°/脉冲** → 角度精度下限由此决定，**必须靠 MPU6050 融合弥补** |
| FG 直线分辨率（估算） | 每脉冲 ≈ 226.19/90 ≈ 2.5mm 行程 | 前进 100cm ≈ 398 脉冲，分辨率足够 |

> 注：FG 的"每转脉冲数"（9 脉冲/电机转）来自规格书，不同批次可能有差异，**固件仍按方案走行程标定实测 K_odo**，上表仅用于预估分辨率量级。

## 3. zip 零件清单里的额外收获（对方案的影响）

| 发现 | 影响 |
|---|---|
| `主控板.SLDPRT`、`RaspberryPi5.SLDPRT` 在模型中占位 | ESP32-S3 替换后需做**转接固定**：DevKitC-1 尺寸约 25.4×60.5mm，可用 2.54 排母 + M3 铜柱借原主控板孔位，或 3D 打印转接板 |
| `电机电池.SLDPRT`（电池模型）| 24V 电池在车中位置已固定，布线时注意动力线远离信号线 |
| `转子-1.SLDPRT`、`磁环.SLDPRT` | 电机内部件，无影响 |
| `线架上/下.SLDPRT` | 原车自带走线架，ESP32 布线可借用 |
| `顶部保护壳.SLDPRT`、`顶板.SLDPRT` | 若顶部空间封闭，注意 ESP32 天线区不能贴金属板（留 10mm 净空） |
| `前后红外传感器固定`、`侧面传感器固定`、`侧面中部红外传感器固定`、`两侧红外测距固定2` | 6 路红外测距的安装位已定：前、后、两侧、两侧中部 —— 雷达图扇区角度按此布置 |

## 4. 整车尺寸

- 官方标注：290 × 230 × 145 mm（长×宽×高，3.5kg 级）
- STEP 包围盒实测偏大（含铲子抬起姿态与转换噪声），以官方标注为准。
- 转向特性：轴距 154 / 轮距 170，比值 0.91，属于**好转向**的短轴距宽轮距布局（README 里第一代"转向困难"的问题在这台 2.0 模型上已缓解），但驼峰轮高摩擦依旧，**转向标定 K_turn 仍不可省**。
