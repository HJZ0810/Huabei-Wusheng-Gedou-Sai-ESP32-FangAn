## V4.0 — 2026-10-06（已发布）

基线：[V3.0 固定标签](https://github.com/HJZ0810/Huabei-Wusheng-Gedou-Sai-ESP32-FangAn/tree/v3.0)。详见 [V4 发布说明](docs/releases/V4.0.md)。完整 Arduino 工程包、19条软件门控和V1～V3历史快照核验均已完成；[GitHub V4.0发布页](https://github.com/HJZ0810/Huabei-Wusheng-Gedou-Sai-ESP32-FangAn/releases/tag/v4.0)提供下载。公网服务布局与回退见 [服务器部署](docs/setup/V4服务器部署.md)。

### 新增

- STA 联网后主动建立 WSS，服务器托管同源公网网页；AP 本地操作保持可用。独立设备凭据与专属控制链接分开，控制链接自动建立Secure Cookie会话，驾驶权继续由排他租约仲裁；只服务一辆车，无账号、密码输入或选车流程。
- 设备单调时钟签发 600ms 短期许可，boot/link/lease/seq 共同检查；拒绝离线排队、过期消费、旧 ACK 和重连自动续跑。
- 现有 FG/惯性增量估计位置，人工设置起点、航向及层面；地图显示误差规模和质量，碰撞、滑移、失效后会降级。
- 380cm 外场/240cm 高台默认地图，低层绕台、高台内缩安全区及点击目标导航；低层高台目标自动组合入口导航和登台。
- 车端有界自主格斗：搜索、测距候选、对准、接近、有限推撞、撤离；缺地/失效/急停和总期限优先。
- 登台入口对正、倾角/行程/越顶/持续停稳支撑证据链；成功仍标为估计高台。低层格斗先登台再继续，独立登台完成后停车，失败不自动反复冲台。
- 灰度向下四角、E18 向下前左/前右/后中、IR 水平周向的原创安装方案；向下 E18 的归一状态 true 表示见地。
- 自主任务断云继续，人工驾驶失联停车；takeover 走停止旁路，后续人工输入重新争用控制权。

### 继承与完善

- 继续使用 V3 唯一电机控制任务、PID、PCNT/中断回退、换向等待、堵转、急停代次和 NVS 成功后发布。
- 专属链接切换立即清旧会话、Socket、租约与遥测，迟到认证响应和旧连接事件不会恢复旧身份；重连仍需手动点击接管，不自动恢复驾驶。
- 本地和云端共用严格指令入口与白名单遥测；云端不开放标定、解锁、WiFi/凭据读取、配置保存或重启。
- 四个固定 Arduino ZIP；WebSockets 2.7.2 附限帧、强制 CA 校验及双核心超时单位补丁，保留许可证及原始/补丁哈希。
- 白蓝简洁的五页可编辑网页，地图与操作优先，单份网页源供本地/云端使用；新增自主合同、默认参数场景与实际 TLS/HTTP/WS 服务端测试。
- 保留 V1/V2/V3 全部历史工程与展开记录。V3快照来自发布后的资料完整提交 be7bbf0，旧标签不移动，快照不递归包含旧版本目录。

### 修复

- 连续模式 0% 被解释为满速上限；电气取反影响逻辑反馈符号；航向纠偏方向错误。
- 偏航折回 ±180° 导致整圈/多圈目标无法正确表示，转向标定受 IMU 精修影响。
- 前馈/补偿后的最终 PWM 饱和未完整反馈给积分，换向等待期间积分累积。
- 舵机 16 位 LEDC 超出 S3 能力，改 14 位并处理初始化失败。
- NVS 写入未检查长度；网页可能把 HTTP 失败显示为成功；保存与运动竞争窗口。
- 采样/异步心跳略晚于周期起点时，无符号时间差误判超时。
- 旁观者页面失焦、切页或关闭时自动发 stop，打断驾驶者。

### 新增与完善

- HTTP/WebSocket 随机连接令牌绑定、同源检查、断线撤销与重连更新。
- 边缘/IR/倾倒独立开关；渐进 IR 限速、无效策略及换向余转方向检查。
- 实际生效的转向角加减速度；保留可调堵转时间与遥测频率并收紧可用范围。
- ADXL345 全分辨率 ±16g，MPU ±2g 替代来源、冲击和饱和显示。
- 候选校验 → NVS 成功 → 发布快照；标定一次性应用仲裁。
- 双版本编译、模块回归、源码/日志哈希绑定与 ZIP 一致性检查。
- 分文件 Arduino 导出、三个固定依赖、离线配置转换、中文注释及安装资料。

### 保留

- 急停/停止旁路、代次失效旧命令、控制权与心跳保护。
- PCNT/毛刺滤波/中断回退、FG 静默及轮速双条件换向等待。
- 非有限数与越界校验、静止零偏判据、离线四页网页、常驻 AP 和可选 STA。

### 升级注意

- 维护源 `combatbot/`，当前入口 `CombatBotArduino/CombatBotArduino.ino`；V2 资料归档。
- NVS `cbot` → `combatfusion` 不自动迁移；PID/协议单位变化，候选需重新校准。
- 六路 IR 通道改等角顺时针排列，必须核对方位与接线。
- 控制目标 200Hz → 100Hz，不作为性能提升宣称。
- 首启保护总开关默认关闭；转换旧保护参数可能启用总开关，导入前核对传感器。
- 保留有效低压 50% 限速，不迁移 `batCrit` 停机或主动制动偏好。
- 未上板，软件通过不等于机械精度或实车验收。

## V2.0 — 历史公开版本

公开日期：2026-10-05。比较基线为 [V1.0 / 1b04fd7](https://github.com/HJZ0810/Huabei-Wusheng-Gedou-Sai-ESP32-FangAn/commit/1b04fd7485a531d5d85fe769732636cfa675b90e)，完整快照对应 [V2.0 最终提交 fd650ac](https://github.com/HJZ0810/Huabei-Wusheng-Gedou-Sai-ESP32-FangAn/commit/fd650ac14d98aebc9779bf88365e23ad4cc5305f)。入口：[历史工程](versions/v2.0/CombatBot_Fusion/) · [原 README](versions/v2.0/CombatBot_Fusion/README.md) · [扩写说明](docs/releases/V2.0.md)。

### 新增与加固

- 停止/急停绕过普通队列，以原子标志请求停止并递增命令代次，使旧队列命令失效；普通队列满不再阻止停止被受理。
- CAS 抢占单一控制权；心跳和服务端断开事件识别控制者，动作结束或新占用入队失败后释放控制权。
- 动作入口拒绝 NaN、Inf 与越界参数；配置落库前按物理范围收口，减少异常值进入状态机。
- FG 优先 PCNT 硬件计数与毛刺滤波，不可用时回退 GPIO 中断。
- 换向同时满足 FG 静默至少 120ms、滤波轮速不高于 0.8cm/s，再切方向输出。
- PID 增加条件积分抗饱和和首拍微分保护，完善控制器切换与受限输出时的处理。
- IMU 零偏标定加入方差判据；在线自适应限定在标定值 ±0.1°/s，避免回写 NVS。
- 传感器增加逐通道有效性与时效检查；无效 IR 遥测输出 JSON `null`、网页显示 `--`。
- IR 按行进方向筛选障碍，原地转向全向判断，减少车后障碍对前进限速的干扰。
- 补充 Arduino IDE 新手指南和针对停止、占用、换向及感知异常的自检项。

### 继承与优势

- 保留 V1 的连续/精准控制、四轮速度环、航向修正、运动规划、三步标定、舵机、NVS 配置与 JSON 导入导出。
- 保留常驻 AP、可选 STA、mDNS、强制门户、HTTP/WebSocket/REST 与可编辑内嵌四页网页。
- 保留目标 200Hz 控制任务、约 20Hz 传感器扫描及分项接线/设计资料。优势是将失效与并发处理补进完整功能链，而非另起一套操作流程。

### 已知边界与历史证据

- 公开快照的心跳保护主要覆盖连续模式；V3 后续覆盖全部运动模式并修正时间戳边界。
- 服务端对旁观者断开有仲裁，页面自动发全局停止仍可能影响驾驶者，V3 后续修复。
- 多圈偏航、最终 PWM 饱和反馈、转向角加减速和 NVS 写成功再发布等边界在 V3 完善。
- 无效 IR 被排除限速并不表示该方向已确认安全；原 `batLow` / `batCrit` 初值也不能替代真实电池规格核验。
- 原 README 保留历史 Arduino-ESP32 3.3.12 编译数据，本次仅恢复公开快照与补充说明，没有重编或上板验证 V2。
- 控制任务绑定 Core 0 不能推导为独占 CPU；目标频率不能证明实测响应或运动精度。

旧资料另保留于 [docs/archive/v2.0](docs/archive/v2.0/)，原版全文随完整工程恢复。不同版本的安装、接线、配置与接口必须分别使用。

## V1.0 — 首个公开工程快照

公开日期：2026-10-05。基线：[1b04fd7](https://github.com/HJZ0810/Huabei-Wusheng-Gedou-Sai-ESP32-FangAn/commit/1b04fd7485a531d5d85fe769732636cfa675b90e)。入口：[历史工程](versions/v1.0/CombatBot_ESP32S3/) · [原 README](versions/v1.0/CombatBot_ESP32S3/README.md) · [扩写说明](docs/releases/V1.0.md)。源码文件内部 V1.1 注释按原样保留，不据此新增一个公开发布版本。

### 建立的功能基础

- 四路电机 PWM、方向输出、FG 中断计数和舵机模块，运动学模块完成脉冲、厘米、角度换算。
- 连续实时差速驾驶；精准直线与转角动作，进度、完成误差和告警通过遥测回传。
- 直线速度规划、四轮速度 PID 与航向修正；转向使用轮脉冲主转、对称补偿及 IMU 精修流程。
- MPU6050 / ADXL345 惯性数据，CD74HC4067 采集六路 IR 与电池，MCP23017 接入灰度/E18。
- 常驻 AP、可选 STA、mDNS、强制门户和内嵌四页网页；提供 HTTP、WebSocket、REST 操作接口。
- NVS 参数持久化、JSON 导入导出，提供 IMU 零偏、行程 `K_odo` 与转向 `K_turn` 标定流程。
- 上电零 PWM、急停锁定、连续模式心跳看门狗、低压限速/严重低压停机、堵转与边缘保护。
- `.ino` 与 `.cpp/.h` 同级的分文件 Arduino 工程，配套 PlatformIO 配置、中文注释、接线参考、设计依据、参数说明及自检清单。

### 阶段价值与后续演进

- 建立从装机、参数、标定到驾驶和遥测的完整链路，能直接在 Arduino IDE 阅读各模块。
- 无须外部网页服务器，操作、调参和数据展示同属固件工程；模块边界便于继续完善。
- V2 在此基础上补停止优先级、并发控制、输入约束、硬件计数和传感器状态；V3 再补控制语义、保存边界与交付证据。

### 历史边界与验证说明

- 停止仍走普通命令处理流程，缺少跨客户端仲裁；输入边界、换向等待、零偏方差与逐通道有效性尚不完整。
- 心跳看门狗主要保护连续模式；目标频率、到位阈值和原说明中的经验性表述不能视为实测性能结论。
- 原文记录曾在 espressif32 6.9.0 / Arduino core 2.0.17 下进行语法与类型校验，本次没有重新编译或上板验证 V1。
- 历史源码和文档完整保留用于追溯；当前部署使用对应版本的安装与接线说明。
