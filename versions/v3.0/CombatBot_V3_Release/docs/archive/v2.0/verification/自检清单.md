# 自检清单（对照设计文档第十节验收标准）

> 逐项打勾后再上场比赛。前 3 项在装机阶段做，4~8 在标定后做。

## A. 硬件与装机

- [ ] FG 四路均已分压到 3.3V（万用表量，空载 <3.3V）
- [ ] 蓝线调速经电平转换器后为 0~5V，并加了 RC 低通
- [ ] 24V/5V 共地（星型单点）、电机端 470µF + 0.1µF 去耦
- [ ] 电机满载启停 10 次，ESP32 **不复位**
- [ ] 未使用任何 H 桥驱动（TB6612/L298N 等）
- [ ] 所有模拟量只走 ADC1（GPIO4），未占用 ADC2
- [ ] I²C 三器件均可扫描到：0x68 / 0x53 / 0x20

## B. 网络与寻址

- [ ] 上电即可搜到 `CombatBot-AP`，连上能打开控制页
- [ ] STA 密码填错 / 路由器断电时，AP 仍可连、仍可控制（**AP 永不关闭**）
- [ ] AP 模式下 `http://combatbot.local` 可访问
- [ ] STA 连上后 `http://combatbot.local` 仍可访问，顶栏徽章显示 `AP+STA`
- [ ] 顶栏同时显示 IP，右上角 ▣ 能生成可扫的二维码
- [ ] 手机连 AP 自动弹页（Captive Portal）
- [ ] 拔掉路由器、纯 AP 直连时页面功能完整（无任何外网依赖）

## C. 连续实时控制

- [ ] 按住摇杆 → 立即启动；松开 → 立即停止（目测无延迟）
- [ ] 端到端响应 ≤80ms，松开到停止 ≤100ms
- [ ] 键盘 W/A/S/D 与方向键可用，空格急停
- [ ] 速度滑条调节的是**最大速度上限(cm/s)** 而非占空比
- [ ] 四轮转速条实时更新，数值合理（同向同速）

## D. 定点精准控制（标定后，硬质平地）

- [ ] 前进 100cm 重复 5 次，误差 ≤ ±2cm
- [ ] 原地转 90° 误差 ≤ ±3°
- [ ] 连续转 360° 累计误差 ≤ ±8°
- [ ] 动作完成后页面正确显示「目标 / 实际 / 误差」
- [ ] 启停有梯形速度规划，无猛冲/急停
- [ ] 快捷预设 10/30/50/100cm 与 45/90/180/360° 均可用

## E. 安全

- [ ] 关页面 / 切后台 / 拔 WiFi → 小车 ≤1s 内自动停车
- [ ] 心跳停止 >1000ms 自动停车
- [ ] 急停按钮任意页面可见，单击即停并锁定，再点解锁
- [ ] 低压告警触发，并自动限速 50%
- [ ] 人为堵住一轮 → 1.5s 内停机并弹告警
- [ ] 舵机行程限位生效，不会顶死机械极限
- [ ] 上电默认不动、舵机回中
- [ ] **（V2 新增）** 连点 20 次「前进」把指令队列塞满后，急停仍能立即生效
- [ ] **（V2 新增）** 开两个页面，A 在摇杆驾驶时 B 发指令被拒绝；关掉 B 不会打断 A
- [ ] **（V2 新增）** 用 REST 发一条 `{"act":"move","dist":1e9}` → 被拒绝，小车不动
- [ ] **（V2 新增）** 零偏标定时故意推一下车 → 页面提示「标定失败：车辆未静止」
- [ ] **（V2 新增）** 拔掉一路红外 → 该路显示 `--`，且不会引起误限速
- [ ] **（V2 新增）** 车尾贴墙往前开 → 不会被限速（方向性过滤生效）
- [ ] **（V2 新增）** 高速前进时直接给反向指令 → 有约 120ms 换向延时，无齿轮冲击声

## F. 配置持久化

- [ ] 修改任意设置项 → 保存 → 重启 → 仍生效（NVS）
- [ ] 配置可导出 JSON，可导入 JSON
- [ ] 恢复默认可用；清除 WiFi 配置可用
- [ ] 重启按钮可用

## G. 代码质量

- [ ] 编译无 error、无阻塞主循环的 `delay`
- [ ] 电机/传感器/IMU 在独立 FreeRTOS 任务（core0，200Hz），WebSocket 在 core1，互不阻塞
- [ ] FG 计数带符号（后退时脉冲数减少）
- [ ] 无外网 CDN 依赖（断网可用）
- [ ] **（V2 新增）** `-Wall -Wextra` 全量告警下，工程自身 0 warning
- [ ] **（V2 新增）** FG 计数走 PCNT 硬件计数（串口可见）；不可用时自动降级为中断计数
