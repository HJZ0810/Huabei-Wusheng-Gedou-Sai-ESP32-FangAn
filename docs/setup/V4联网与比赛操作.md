# V4 联网与比赛操作

本地入口仍为 `http://192.168.4.1`，公网入口为 `https://combatbot.luo-jin-ai.com/`。独立服务已部署，证书、公网协议替身和浏览器专属链接检查通过，记录见 [部署记录](V4服务器部署.md)；最终软件发布证据见 [发布记录](../releases/V4.0.md)。私有控制链接另存仓库外。公网网页不要求浏览器与车同一WiFi，但车必须STA联网、能出站访问443、完成时间同步并通过CA证书校验。

## 配置联网

1. 先通过AP打开本地设置页，填写STA SSID/密码。不要因为启用STA删掉AP入口。
2. 设置云主机 `combatbot.luo-jin-ai.com`、端口443、路径 `/ws/device`、分配的deviceId及独立deviceKey，粘贴受信任CA PEM；设备密钥不与WiFi密码或控制链接密钥共用。
3. 本地保存配置，按页面提示重启。只有STA已联网、云启用、时间与CA条件满足才主动建立WSS；缺CA不降级验证。
4. 打开提供的专属控制链接，页面自动建立单车会话，无需账号、输入或选车。看到在线和新鲜真实遥测后，手动点击“接管控制”取得驾驶租约；打开链接不自动接管。控制链接和设备配置保存在仓库外受限文件，不写公开文档。

云端解锁、标定、参数、WiFi及重启保持本地操作；云配置GET不回显deviceKey，未修改密钥字段时不提交空值覆盖。

专属链接形如 `https://combatbot.luo-jin-ai.com/#control=随机控制密钥`，此处是格式占位，真实链接另行交付。页面读取片段后使用同源HTTPS连接接口建立受限Cookie，并移除地址栏片段；设备WSS密钥不放在该链接里。服务仅对应一辆车，多个浏览器仍需排他取得驾驶权。

## 准备场地与起点

默认380×380cm外场、240×240cm中央高台，世界原点在场地中心。X向右、Y向上，航向0°朝+X、90°朝+Y。车身尺寸、入口和安全余量使用实际安装值；数字探头不能自动识别场地绝对坐标。

按 [安装校准](../hardware/V4传感器安装与校准.md) 完成电平、各色支撑检测、FG/惯性和实测滑行后，本地启用arenaEnabled/arenaCalibrated。确认机械爬阶及试验后再启用arenaClimbEnabled。保持车体停稳，在竞技页设置起点、航向及低层/高台；这一步不自动运动。

## 地图导航、自动格斗和登台

地图点击先选择目标，按“执行导航”才提交。车端再次校验场地、车身、误差和路径；有颜色的区域并不保证允许导航。高台目标要求在内缩安全区，低层路线绕中央高台，不支持自动从高台跳下。低层点击高台目标时，符合条件才组合入口路线、登台和目标导航。

自动格斗在车端搜索测距候选、对准、接近、有限推撞及撤离。低层启动时先自动登台；独立“登台”完成后停稳。IR候选不保证就是对手，界面位置和轨迹是估计，quality不是实测置信概率。登台完成只标“估计高台”，证据不足停止并等待检查及重新锚定；不会无限冲台。

## 断网、取消与人工干预

自主导航/格斗/登台一旦明确启动，关闭页面或云断线不会取消车端任务；仍受本机防掉、必要输入、急停和最初总期限约束。人工驾驶使用应用心跳，失联停车。不能依赖关闭网页停止自主。

“取消/停止”取消任务，“人工接管”先停车清旧代次，再由后续手动指令重新申请控制；急停锁定后必须本地检查并解锁。远端持有控制租约会话的停止/急停受有效租约和在线链路约束，网页按钮无法保证公网断线时送达；现场保留本地操作与物理断电手段。

切换专属链接会清旧会话、Socket、租约和遥测；迟到认证响应及旧连接不能恢复旧身份。重连先查看最新遥测和层面，再手动接管。系统不会自动恢复人工驾驶、重投旧指令或重新开始比赛。若坐标偏移、碰撞、层面未知或支撑检测异常，停止并检查，停车后修正起点，再明确开始新任务。
