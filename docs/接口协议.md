# 本地控制接口

接口运行在设备局域网HTTP服务，不依赖云端账户。连接凭据不构成账户身份认证；有WiFi接入能力的客户端仍能握手。不要把设备服务直接映射到公网。

## 握手与会话

连接同源 `ws://设备地址/ws`，先接收：

```json
{"t":"hello","client":11,"session":"128位随机值的32字符十六进制编码","firmware":"5.0.0"}
```

后续HTTP加 `X-CombatBot-Session: 会话值`，JSON请求加 `Content-Type: application/json`。服务端根据凭据查询连接，不能用广播owner编号作为凭据；动作/标定可省略body.client，填写时必须与会话一致。配置JSON只包含配置字段，不加client。首次GET配置只要求握手，不必先等遥测；动作网页仍要求连接和新鲜遥测。

`firmware` 表示发行版本，仅供诊断；它不是会话凭据，也不改变控制命令的含义。

凭据仅hello单播，不进入URL、NVS、日志或遥测广播。最多4个会话，断开/错误撤销，重连重新生成；浏览器Origin必须与Host同源，无Origin的本地工具保留兼容。HTTP不是加密传输，此机制不解决WiFi接入控制或网络窃听。

## HTTP

| 方法/路径 | 输入 | 结果 |
|---|---|---|
| GET / | 无 | gzip离线HTML |
| GET /api/config | 会话头 | 本地配置，含WiFi密码但不回显云设备密钥，禁止缓存 |
| POST /api/config | 部分配置JSON | 完整校验，NVS成功后发布 |
| POST /api/config/defaults | {} | 恢复融合默认 |
| POST /api/config/clear-wifi | {} | 清STA/恢复AP，重启生效 |
| POST /api/action | 动作JSON | 202受理，不等同执行完成 |
| POST /api/calibrate | 标定JSON | 启动或应用对应结果 |
| POST /api/reboot | {} | 先登记停车，约500ms后重启 |

配置变更先申请控制器空闲窗口；普通命令消费与保存共享仲裁，保存期间仍受理停止/急停。写入失败不发布新配置。请求体最大8192字节。

响应形如 `{"ok":true,"message":"说明"}`。常见状态：400参数或保存失败，401会话无效，403连接编号不匹配，409控制冲突/忙/锁定。网页同时判断HTTP状态与ok，不把收到响应等同保存成功。

## 控制命令

WebSocket无需重复发送HTTP凭据，指令绑定触发事件的连接。只接受完整文本JSON，最大2048字节，不支持分片/二进制。

```json
{"t":"drv","x":0,"y":1,"spd":20}
{"t":"hb"}
{"t":"stop"}
{"t":"estop"}
{"t":"unlock"}
{"t":"move","dist":100}
{"t":"turn","deg":360}
{"t":"servo","pos":0.5}
{"t":"cal","mode":"imu"}
{"t":"pose","x":0,"y":-160,"heading":90,"floor":"lower"}
{"t":"goto","x":0,"y":0}
{"t":"auto"}
{"t":"climb"}
{"t":"takeover"}
```

连续x/y范围[-1,1]，x右/y前为正，spd为最大线速度百分比[0,100]。距离±0.5～1000cm，转角±1～1440°，正转角左转。servo归一位置[0,1]按配置端点映射。心跳仅当前控制者可刷新；网页运行动作时约200ms一次。STOP/ESTOP任何有效连接均可提交，停止请求绕过普通队列容量。

V4 世界坐标以场地中心为原点，X 向右、Y 向上，单位 cm；航向从 +X 逆时针计度。`pose` 指定 `lower` / `upper`，只在车体已停稳时接受；更新参考不会自动启动。`goto` 还需通过车身外包络、层面、定位误差及路径检查，地图中选点并不等于一定可执行。`auto` 启动有总期限的自主格斗；`climb` 是独立登台，完成后停止。低层格斗或高台导航按条件先完成入口与登台，再继续原任务。

`takeover` 通过停止旁路取消当前任务、清理旧代次；随后人工动作重新申请控制权。自主受理后转交车端 owner，浏览器心跳不能延长预算；自主期间云断线不会取消任务。人工动作仍需要心跳。云端仅允许持有专属控制链接的会话取得单车排他租约，stop/estop 也受控制能力和租约约束；本地有效连接仍可发送停止和急停。云解锁、标定、配置和重启保留本地。

标定启动HTTP `{"mode":"odo"}` / `{"mode":"turn"}` / `{"mode":"imu"}`，或WS对应cal。行程/转向完成后HTTP提交 `{"mode":"odo","measured":实际厘米}` 或turn实际累计度数。仅最近同类型结果可应用一次；IMU由控制器静止采样保存，无外部measured换算。

## 遥测与完成

tm包含速度/yaw/odo、四轮rpm/pulses/pwm、IR距离与有效性、数字输入、加速度、网络IP、状态、故障、控制者与完成度。新增字段为accelSource、accelSaturated、impact、impactG、irLimited、irUnavailable、irSpeedScale。

accelSource：0无有效源、1为MPU±2g、2为ADXL±16g。IR/电池无效以null表示；impact是当前测量超阈值，饱和另外表示幅度未知。IR限速信息是最近运动检查结果。

done包含type、target、actual、err、id及标定脉冲。误差为actual-target，单位随动作cm/°/零偏°/s。id仅本次启动递增，不能跨重启当作历史编号；完成是软件估计到位，不代表尺量精度已验收。


## V4 地图遥测与云端协议

`tm.arena` 提供 `x/y/heading/uncertainty`、`quality`、`floor`、`mode/phase/reason`、`active`、场地尺寸、入口参考、导航目标与测距候选。没有起点时位姿字段为 `null`。`quality` 的 high/medium/low 只是误差模型分档，不是实验标定后的概率置信度；`floor` 的 upper/upper_estimated 分别对应人工高台锚定/登台估计。telemetry 的 transition 对应内部未知过渡层。候选不能证明对手身份。

云端专属链接会话、设备 WSS、短期许可、lease/seq 和 ACK 代次的完整合同见 [server/README](../server/README.md)。设备 `boot/link/permit` 与服务器租约共同阻止旧连接、重放及过期指令；原许可期限在车端入口和队列消费均检查。重连不重放人工动作或自主启动。


公网部署入口为 `https://combatbot.luo-jin-ai.com/`。控制链接采用 `#control=独立随机密钥` 片段，浏览器读取后通过同源HTTPS `POST /api/connect` 提交 `{controlKey}`，服务端核对摘要并设置Secure/HttpOnly/SameSite Cookie；网页移除片段，设备密钥仍只用于车端WSS。无账号、用户名、密码输入或车辆选择接口。一个云设备连接和一个远端驾驶租约保持单车仲裁；专属链接与设备配置存于仓库外，不收录公开附件。
